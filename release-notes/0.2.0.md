## Zirtola Launcher 0.2.0

- **What's new** for every game: release notes per version, with your installed version highlighted. Shown after each update.
- **Beta channel**: testers with beta access can switch a game to beta updates and back.
- **One PC per licence**: if your game is active on another PC, the launcher shows which one and lets you move it here.
- Buying from the launcher now opens the website's checkout and the game appears as soon as the purchase goes through.
- Offline play: games keep working for 7 days on their last licence check.
