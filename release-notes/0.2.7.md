## Zirtola Launcher 0.2.7

**Fixes**
- **More ways to open on PCs where WebView2 won't start.** One more try, starting WebView2 exactly as a plain app does.
- **A launcher that still can't open now records why.** The startup log gets WebView2's own error log, any crash reports it left, and overlay, audio-enhancer or RGB programs that are running, which are a common reason WebView2 fails on one PC. If yours won't open, send `%LOCALAPPDATA%\Zirtola Launcher\logs\startup.log` in #help.
