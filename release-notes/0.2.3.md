## Zirtola Launcher 0.2.3

**Fixes**
- **A game that only has a beta build can now be installed.** Install used to say there was nothing to download, because a first install only looked for a public build. If your account has Beta access, the launcher now installs the beta build and shows "Beta: on" for that game.
- **Clearer message** when a game has no public build yet and your account has no Beta access.
